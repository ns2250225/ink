# 落笔成画

> 键入文字，墨自成景。

「落笔成画」是一个纯前端的网页水墨画生成器：在输入框里写下一个字、一个词，甚至一整句古诗，页面便会现场挥毫——远山、江水、孤舟、飞雪、月下渔翁……一幅中国水墨画徐徐展开，所写文字化作题跋，末了还自动钤上一方朱印。

整个项目只有一个 `index.html`，原生 JavaScript + Canvas，**零依赖、零构建**，打开即用。

---

## ✨ 特性

- **键入即画**：输入汉字自动构思构图，字先浮现于纸上，再化入画中
- **400+ 意象字词**：山水云月、草木花树、亭台舟桥、人物鸟兽鱼虫，每个字都是画中一景
- **认识英文**：`mountain`、`moon`、`snow`、`lotus` 等常见英文词也能直接入画
- **题跋钤印**：所写文字以竖排小字题于右上，停笔片刻自动盖上「落笔成画」朱文印章
- **一键题诗**：内置「孤舟蓑笠翁，独钓寒江雪」「明月松间照，清泉石上流」等诗句，自动成画
- **以指为笔**：鼠标或手指在纸上拖动可扫出干笔飞白，点按则落墨晕染、点水生涟
- **画面是活的**：游鱼摆尾、小舟随波、柳丝拂风、飞雪落雨、花瓣飘零、萤火明灭，皆为动画
- **细节讲究**：宣纸纹理、墨分五色、远山淡墨、近景浓墨，图层以正片叠底混合
- **贴心适配**：响应式布局、移动端触屏、刘海屏安全区、`prefers-reduced-motion`、低功耗 `?fast` 模式

## 🚀 快速开始

无需安装任何东西，直接用浏览器打开 `index.html` 即可；也可以部署到任意静态托管（GitHub Pages、Vercel 等）。

```bash
git clone https://github.com/ns2250225/ink.git
cd ink
# 直接双击 index.html，或起一个静态服务：
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

### URL 参数

| 参数 | 说明 |
| --- | --- |
| `?t=明月松间照` | 打开页面后自动以此为题作画 |
| `?fast` | 快进动画节奏，适合截图或低性能设备 |

## ⌨️ 交互

| 操作 | 效果 |
| --- | --- |
| 输入文字 | 即时入画，字化题跋 |
| <kbd>Enter</kbd> | 换行（题跋另起一列） |
| <kbd>Esc</kbd> | 换纸（清空画面） |
| 任意按键 | 自动聚焦输入框 |
| 底部字块 | 点选一字直接入画 |
| 画布上拖动 | 干笔皴擦，扫出飞白 |
| 画布上点按 | 落墨晕染，点在水面则生涟漪 |

顶部工具栏：**换纸**（清空）· **题诗**（自动题一句古诗）· **存画**（导出 PNG）。

## 🧰 技术实现

- **单文件架构**：全部页面、样式与逻辑都在 `index.html` 中，原生 JavaScript + Canvas 2D，无框架、无依赖、无构建
- **多层画布**：纸 / 远 / 中 / 近 / 活动 / 题跋 六层 canvas 以 `multiply`（正片叠底）混合，叠出宣纸上的墨色层次
- **程序化生成**：山形由一维分形噪声（fBm）生成天际线并据此裁剪天空；墨点、墨团、远山均为逐帧晕开的动画
- **字词解析**：单字映射到场景绘制函数，复合词最长优先匹配（如「瀑布」「萤火虫」），常见英文词反向映射到汉字意象
- **书法字体**：[马善政楷体 Ma Shan Zheng](https://fonts.google.com/specimen/Ma+Shan+Zheng)（Google Fonts，SIL Open Font License 开源授权），已随仓库附带于 `fonts/` 目录
